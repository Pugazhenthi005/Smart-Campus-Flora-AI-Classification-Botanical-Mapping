Dataset Audit & Limitations Notice

Each species contains only 2 to 6 images in the primary dataset (average: 2.7 images/class). While transfer learning enables rapid feature extraction, this sample size is mathematically small for definitive field classification. Validation accuracy will fluctuate. Do not rely on predictions for safety-critical or medicinal uses without botanical verification.
